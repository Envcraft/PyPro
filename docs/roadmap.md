# PyPro Roadmap

## Skill Progression Path

```
Level 1: Fundamentals
  ├── 01 CLI Calculator         (Variables, functions, exceptions)
  ├── 02 Number Guessing Game   (Loops, random, input validation)
  └── 03 Expense Tracker        (Lists, dicts, comprehensions)

Level 2: Intermediate Python
  ├── 04 Contact Manager        (CRUD, JSON, file I/O)
  ├── 05 File Organizer         (pathlib, automation, logging)
  └── 06 CLI Task Manager       (OOP, dataclasses, enums)

Level 3: Advanced Python
  ├── 07 Log Analyzer           (Regex, generators, collections)
  ├── 08 REST API Client        (HTTP, auth, retry logic)
  └── 09 Web Scraper            (HTML parsing, rate limiting)

Level 4: Backend Engineering
  ├── 10 Inventory System       (SQLite, transactions, repos)
  ├── 11 Concurrent Processor   (asyncio, threading, benchmarking)
  └── 12 Production REST API    (FastAPI, JWT, Docker, testing)
```

## Concepts by Level

### Level 1
Variables, data types, operators, arithmetic, conditions, loops, functions, input validation, exception handling, random module, lists, dictionaries, comprehensions, data aggregation.

### Level 2
CRUD operations, JSON serialisation, file I/O, pathlib, os, shutil, automation, logging, OOP, classes, dataclasses, enums, type hints, datetime, sorting, filtering.

### Level 3
Regular expressions, generators, collections.Counter, file streaming, HTTP clients, authentication, retry logic, HTML parsing, rate limiting, CSV, SQLite.

### Level 4
Relational databases, SQL, database transactions, repository pattern, asyncio, async/await, threading, concurrent.futures, performance benchmarking, FastAPI, JWT, Docker, API testing.
