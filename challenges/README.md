# Challenges

Weekly coding challenges to supplement the main projects.

Challenges are independent of the main project track. They are shorter, focused exercises (1–3 hours each) designed to reinforce specific Python concepts.

---

## Structure

Each challenge lives in `weekly-challenges/week-NN-topic/`.

---

## How to Use

1. Read the challenge description.
2. Implement your solution independently.
3. Compare against the acceptance criteria.
4. Optionally request a review.
